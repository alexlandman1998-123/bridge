Listing Event Feed API
We have implemented a listing event feed that will contain information around events that occur in the private property system and affect your or
your clients listings.
Using this feed will reduce unnecessary calls to GetListingStatus and GetLisitngSummary
GetListingStatus and GetLisitngSummary required you check if a status has changed to Active in order for you to get the PrivateProperty Ref.
Using the listing event feed you will receive this information as it becomes available and no longer have to call GetListingStatus and
GetLisitngSummary for this information.
From the listing event feed you will be able to tell as and when a listing:
1. gets activated (PP Ref will be provided).
2. images are downloading.
3. images have downloaded.
4. image downloads failed (a new listing will not be activated until images are resolved).
5. is removed. (Expired eg.culling, Branch de-activation)

Implementation
There are 2 ways you can use the listing event feed:
1. By Feed Provider:
You will receive updates for listings that belong to all branches you service.
You will only be required to store one Continuation Key.
2. By Branch:
You will receive updates for listings that belong to a specified branch that you service.
You will be required to store one Continuation Key per Branch.

method GetPrivatePropertyListingEventFeed()
{
//get BranchIds
branchIds = getBranchIds();
foreach( var branchId in branchIds )
{
bool moreToProcess = true
var continuationKey = "";
While (moreToProcess)
{
if(continuationKey is empty) // if empty, try and retrieve.
{
continuationKey = getContinuationKeyForBranch(branchId) //you
will have to store a key somewhere per branch.
startDateTime = null;
}
// if still empty you do not have a key for this branch,
// set up your first call for the branch.
// when you add new branches this sets them for the event feed
if( continuationKey is empty )
{
continuationKey = "0"
startDateTime = DateTime.Now - 2 days
}
var token = getToken() // However you currently do this
var responce = null;

continuationKey, token, branchId, startDateTime )
else
responce = call ppService.GetListingEventFeedByBranch(
continuationKey, token, branchId )
if( continuationKey != responce.ContinuationKey ) // You
have a new key
{
continuationKey = responce.ContinuationKey
SaveNewContinuationKeyForBranch( responce.
ContinuationKey, branchId ) // save it over the old one

(event.EventDescription)

// Inform user/agent that there is an issue
with images

}
}
if (responce.LisitngEventFeedData.count < 100) // No more
updates for this branch
{
moreToProcess = false;
}
}
