Listing Event Feed API
We have implemented a webservice method that allows a feed provider to add You Tube video Id
as well as Matterport Id to a listing on Private Property. The method works after a listing is
published to the portal.
Customers must contact Private Property Support should they wish to add HD higher ranking.
Implementation
Web services:
• UpdateListingVideoOrMatterport (BranchId, PropertyId, ListingType, ListingId,
MatterportId, VideoUrl, Token)
Requirements:
1. YoutubeVideoId. YoutubeVideoId must be 11 characters.
2. Matterport Id
Possible Errors:
1. Validate Listing, Return error if listing is not found (Error code PP103 - Invalid Listing)
2. Validate Branch against the Listing, Return error if listing does not belong to branch (Error
code PP103 - Invalid Listing)
3. Return Error if update fails (Error code PP50 - General Exception).
