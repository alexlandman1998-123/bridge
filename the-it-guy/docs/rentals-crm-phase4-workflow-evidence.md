# Rentals CRM Phase 4 — Workflow Evidence

Phase 4 makes selected pipeline milestones evidence-backed. The lead remains a CRM record; an evidence event is a dated operational note, not a substitute for a legal document, completed screening decision, or tenancy record.

| Workflow milestone | Required record before advance |
| --- | --- |
| Tenant qualified | Explicit qualified confirmation |
| Viewing scheduled | Scheduled date and time |
| Viewing completed | Attended outcome |
| Application submitted | Application reference |
| FICA complete | Evidence reference |
| Appraisal scheduled | Scheduled date and time |
| Appraisal completed | Milestone note |
| Mandate signed | Mandate reference and signed date/time |

Evidence is written into the versioned rental CRM metadata and summarised in the shared CRM activity timeline. It is intentionally not used as proof that a mandate is legally enforceable, that FICA is compliant, or that a tenant is approved.
