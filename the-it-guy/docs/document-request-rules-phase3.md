# Document Request Phase 3: Deterministic Rules

Phase 3 makes onboarding answers—not labels or generic amenities—the reason a document is requested.

## Buyer and finance rules

- Cash purchases request proof of funds and do not request bond affordability evidence.
- Bond and hybrid purchases branch by the declared employment type.
- Self-employed and company-director applicants request six consecutive months of bank statements, current financial statements, tax evidence, and an accountant letter where applicable.
- An ANC spouse who is not a co-purchaser is recorded as a related party but is not assigned purchaser identity or address uploads.
- Every buyer request carries a rule-set version, trigger code, and the normalized onboarding facts used to select it.

## Property compliance rules

- Gas installations trigger a gas compliance certificate.
- Solar or inverter installations trigger an electrical COC and applicable SSEG documentation.
- Electric fencing triggers its compliance certificate.
- Garden, pool, water-tank, security, and similar amenities do not trigger document requests.
- A borehole records a property fact. It only creates a certificate request when an explicit legal, municipal, or contractual requirement is captured.

Participant labels and upload-on-behalf behaviour remain governed by Phases 1 and 2.
