# Listing Portal Checklist - Phase 7

Phase 7 adds a shared publishing checklist to the sales and rental listing workspaces.

## What Changed

- Sales listings now show a checklist under the publishing next-step panel.
- Rental listings now show the same checklist pattern.
- The checklist separates portal setup issues from listing field issues.
- The checklist uses the same Property24 and Private Property readiness summaries as the portal cards.
- The checklist covers four user-friendly steps:
  - portal setup,
  - listing details,
  - readiness check,
  - publish tracking.

## What Did Not Change

- No Property24 payload mapping changed.
- No Private Property payload mapping changed.
- No publishing API calls changed.
- No database fields were added.
- No automatic live publishing was added.

## Why This Matters

The user can now see whether publishing is blocked by setup, missing listing data, an unchecked preview, or live portal tracking. This keeps the workflow practical for normal agents while preserving the existing backend publishing controls.
